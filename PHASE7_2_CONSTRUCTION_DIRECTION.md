# Lunar Konstruksi — Fase 7.2 Construction Direction

Fase ini menggeser bahasa visual Lunar dari editorial-luxury ke construction-first yang lebih grounded.

## Karakter utama
- White / warm white sebagai canvas utama.
- Charcoal untuk section teknis dan footer.
- Construction orange sebagai aksen utama.
- Blueprint line pattern tipis, bukan dekorasi berlebihan.
- Hero split antara copy dan project visual.
- Stats block, services grid, project strip, workflow, quality assurance, CTA.
- Sedikit radius; mayoritas box lebih tegas.
- Copywriting lugas, berbasis fungsi dan proses kerja.

## Inspirasi visual
Referensi user menunjukkan landing page construction modern dengan struktur:
1. Utility header + navigation.
2. Hero project visual + CTA.
3. Achievement/statistics.
4. Company intro.
5. Services.
6. Project inquiry CTA.
7. Quality / process credibility.
8. Projects.
9. Team / trusted company information.
10. Footer.

Implementasi Lunar tetap memakai CMS dan data Firestore, bukan halaman statis.
