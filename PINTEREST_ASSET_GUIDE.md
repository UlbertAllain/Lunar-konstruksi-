# Pinterest image shortlist — Lunar Konstruksi

Pinterest dipakai sebagai referensi pencarian visual, bukan sebagai hotlink production. Simpan aset yang memang kamu punya izin pakai ke `public/images/site/`.

## Slot yang disarankan

1. `hero-construction.*`
   - Wide construction site / crane / structural frame.
   - Golden hour atau daylight netral.
   - Hindari foto terlalu stock-looking.

2. `engineer-blueprint.*`
   - Engineer / architect memegang blueprint.
   - Cocok untuk circular inset di hero.

3. `capability-building.*`
   - Modern concrete / commercial architecture.
   - Dipakai sekali pada section capabilities.

4. `capability-field.*`
   - Rebar / concrete / site execution close-up.

5. `capability-detail.*`
   - Material / structural detail / reinforcement.

## Pinterest search phrases
- modern construction site crane editorial photography
- architect engineer blueprint construction site
- modern concrete architecture editorial photography
- rebar construction worker close up
- architectural blueprint desk construction planning

## Rule
- Asset lokal satu kali pakai → hero / decorative storytelling.
- Project / Service / Team card → media record database masing-masing.
- Jangan reuse satu gambar untuk menutup slot kosong.
- Kalau gambar kosong → placeholder teknis Lunar.
