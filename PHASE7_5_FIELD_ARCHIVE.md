# Lunar Konstruksi — Phase 7.5 FIELD ARCHIVE

Public redesign mengikuti referensi editorial archive / field dossier:

- warm paper / kraft / ink palette
- serif display + condensed sans metadata
- archive labels, reference numbers, ledger tables, stamps, clipped photos
- strong ruled grid instead of rounded SaaS cards
- minimal orange-red accent
- media always resolved from Firestore / Cloudinary records first
- no Unsplash, no AI stock photo, no random external visual fallback

Data mapping:
- hero visual: first published Project media
- project archive: Projects collection
- service index: Services collection
- team personnel records: Team collection
- client notes: Testimonials collection
- FAQ index: FAQ collection
- navigation/settings: CMS Navigation + Site Settings

If media is empty the UI uses a technical archive placeholder only.
