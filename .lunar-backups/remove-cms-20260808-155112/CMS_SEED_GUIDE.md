# Lunar Konstruksi — CMS Seed

Seed ini disediakan untuk mengisi fondasi konten semua system page setelah Full CMS + Public Redesign aktif.

Buka:

`/admin/cms/seed`

Lalu klik **Seed semua halaman**.

Seed melakukan:
- upsert dan publish Home
- upsert dan publish About
- upsert dan publish Services
- upsert dan publish Projects
- upsert dan publish Contact
- mengisi Navigation
- mengisi copy dasar Site Settings + SEO
- revalidate public site

Seed tidak menimpa koleksi Services, Projects, Team, Testimonials, atau FAQ. Data koleksi tersebut tetap dikelola melalui Content Hub agar data asli dan media Cloudinary aman.
